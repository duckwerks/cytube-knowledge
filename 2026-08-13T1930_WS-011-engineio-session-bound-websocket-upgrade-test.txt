WS-011
Date: 2026-08-13
Purpose: Test whether Cytube's Engine.IO WebSocket endpoint requires the WebSocket upgrade to be bound to the exact Engine.IO polling session SID established immediately beforehand. WS-008 showed that a standalone WebSocket handshake to wss://cytu.be/socket.io/?EIO=4&transport=websocket returns HTTP 400, while polling successfully establishes an Engine.IO session advertising websocket as an upgrade. This test performs a fresh polling handshake, extracts the Engine.IO SID, then attempts the WebSocket upgrade using that exact SID and compares the result with a WebSocket attempt without SID.
Target: https://cytu.be/r/EMAIL
Evidence type: EXPERIMENTALLY-CONFIRMED

=== ENGINE.IO SESSION-BOUND WEBSOCKET TEST ===

Run the following from Termux:

python - <<'PY'
import json
import ssl
import sys
import time

import requests
import websocket

BASE = "https://cytu.be"
ROOM = "https://cytu.be/r/EMAIL"
UA = "Mozilla/5.0 (Android 10; Mobile; rv:153.0) Gecko/153.0 Firefox/153.0"

print("=== WS-011 TEST PARAMETERS ===")
print("HTTP :", BASE)
print("ROOM :", ROOM)
print("UA   :", UA)
print()

s = requests.Session()
headers = {
    "User-Agent": UA,
    "Origin": BASE,
    "Referer": ROOM,
}

print("=== STEP 1: FRESH ENGINE.IO POLLING HANDSHAKE ===")
try:
    r = s.get(
        BASE + "/socket.io/?EIO=4&transport=polling",
        headers=headers,
        timeout=10,
    )
    print("HTTP status:", r.status_code)
    print("Content-Type:", r.headers.get("content-type"))
    print("Response:", repr(r.text[:1000]))
    r.raise_for_status()

    body = r.text
    if not body.startswith("0"):
        print("Unexpected Engine.IO response; missing OPEN packet")
        sys.exit(1)

    info = json.loads(body[1:])
    sid = info["sid"]
    upgrades = info.get("upgrades", [])

    print("Engine.IO SID:", sid)
    print("Advertised upgrades:", upgrades)
    print("Ping interval:", info.get("pingInterval"))
    print("Ping timeout:", info.get("pingTimeout"))
    print("Max payload:", info.get("maxPayload"))
except Exception as e:
    print("POLLING HANDSHAKE FAILED:", type(e).__name__, repr(e))
    sys.exit(1)

cookie = "; ".join(f"{c.name}={c.value}" for c in s.cookies)
print("Cookies:", repr(cookie))
print()

ws_headers = [
    "User-Agent: " + UA,
    "Origin: " + BASE,
    "Referer: " + ROOM,
]
if cookie:
    ws_headers.append("Cookie: " + cookie)

print("=== STEP 2: WEBSOCKET UPGRADE USING EXACT POLLING SID ===")
ws_url_sid = BASE.replace("https://", "wss://") + "/socket.io/?EIO=4&transport=websocket&sid=" + sid
print("URL:", ws_url_sid)
print("Headers:")
for h in ws_headers:
    print(" ", h)
print()

try:
    ws = websocket.create_connection(
        ws_url_sid,
        host="cytu.be",
        header=ws_headers,
        timeout=10,
        sslopt={"cert_reqs": ssl.CERT_REQUIRED},
    )
    print("=== SID-BOUND WEBSOCKET CONNECTED ===")
    print("SUCCESS")
    ws.settimeout(5)
    try:
        while True:
            msg = ws.recv()
            if msg is None:
                print("FRAME: <None>")
                break
            print("FRAME:", repr(msg))
    except Exception as e:
        print("RECEIVE COMPLETE:", type(e).__name__, repr(e))
    ws.close()
except Exception as e:
    print("=== SID-BOUND WEBSOCKET FAILED ===")
    print(type(e).__name__)
    print(repr(e))

print()
print("=== STEP 3: WEBSOCKET WITHOUT SID CONTROL ===")
ws_url_no_sid = BASE.replace("https://", "wss://") + "/socket.io/?EIO=4&transport=websocket"
print("URL:", ws_url_no_sid)

try:
    ws = websocket.create_connection(
        ws_url_no_sid,
        host="cytu.be",
        header=ws_headers,
        timeout=10,
        sslopt={"cert_reqs": ssl.CERT_REQUIRED},
    )
    print("NO-SID WEBSOCKET CONNECTED")
    try:
        print("FRAME:", repr(ws.recv()))
    except Exception as e:
        print("RECEIVE:", type(e).__name__, repr(e))
    ws.close()
except Exception as e:
    print("NO-SID WEBSOCKET FAILED")
    print(type(e).__name__)
    print(repr(e))

print()
print("=== STEP 4: CLEAN UP ENGINE.IO POLLING SESSION ===")
try:
    close_url = BASE + "/socket.io/?EIO=4&transport=polling&sid=" + sid
    close_headers = dict(headers)
    close_headers["Content-Type"] = "text/plain;charset=UTF-8"
    close = s.post(close_url, headers=close_headers, data="1", timeout=10)
    print("Close POST status:", close.status_code)
    print("Close response:", repr(close.text[:500]))
except Exception as e:
    print("CLOSE ERROR:", type(e).__name__, repr(e))

print()
print("=== WS-011 COMPLETE ===")
PY

=== INTERPRETATION ===

1. If the SID-bound WebSocket succeeds while the no-SID WebSocket returns 400, the failure observed in WS-008 is explained by the missing Engine.IO session binding. The upgrade path requires the polling SID.
2. If both WebSocket attempts return 400, the issue is not simply the missing SID. Investigate Cloudflare/proxy behavior, WebSocket upgrade headers, Engine.IO implementation details, or Cytube's server-side upgrade policy.
3. If the SID-bound WebSocket succeeds and returns an Engine.IO OPEN/NOOP or Socket.IO-related frame, record the exact frame sequence. Do not infer Socket.IO namespace success until the Engine.IO upgrade and Socket.IO packets are separately identified.
4. If the SID-bound attempt fails but the polling session remains valid, preserve the exact HTTP status and response headers for WS-012.

=== IMPORTANT OBSERVATION FROM WS-008 ===

WS-008 established experimentally that:
- GET /socket.io/?EIO=4&transport=polling returns HTTP 200.
- The Engine.IO OPEN packet advertises upgrades:["websocket"].
- A direct WebSocket request to /socket.io/?EIO=4&transport=websocket returns HTTP 400 from the Cloudflare-fronted Cytube endpoint.
- The next diagnostic question is therefore whether the WebSocket request must carry the exact SID created by the polling handshake.
